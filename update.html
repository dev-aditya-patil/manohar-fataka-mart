How to update prices

  1. Edit prices in Product_list_2k26.xlsx (keep the same column headings: Sr No., Category, Product Name, Brand, Box Pack/ Qty, Function, Rate).
  2. Choose the Excel file below. It is read only inside this browser; nothing is uploaded anywhere.
  3. Check the summary, then tap Download products.json.
  4. On GitHub, upload the downloaded products.json to the repository, replacing the old one. The website shows the new prices within a few minutes.
